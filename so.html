O que são sistemas operacionais?

Um sistema operacional é o software principal de um computador. Ele coordena o uso do processador, da memória, dos arquivos e dos dispositivos conectados, além de oferecer uma interface para que as pessoas executem aplicativos. Windows, macOS e sistemas baseados em Linux são exemplos usados em computadores pessoais. Cada família possui diferentes versões, recursos e requisitos de hardware.

Versões do Windows

O Windows é um sistema operacional desenvolvido pela Microsoft. Sua história começou com o Windows 1.0, lançado em 1985 como um ambiente gráfico para computadores compatíveis com PC. O Windows 3.0 e o 3.1 ampliaram sua popularidade; o Windows 95 marcou uma grande mudança na interface, com o menu Iniciar e a barra de tarefas. Depois vieram Windows 98 e Me, seguidos por versões importantes como XP, Vista, 7, 8 e 8.1. O Windows 10 foi lançado em 2015 e o Windows 11 em 2021. Além dos nomes principais, a Microsoft publica atualizações de recursos identificadas por números e anos, como 22H2 e 24H2. O Windows 11 é a geração mais recente dessa linha; o suporte regular ao Windows 10 terminou em outubro de 2025.

Versões do macOS

O macOS é o sistema operacional dos computadores Mac, desenvolvido pela Apple. A família moderna começou com o Mac OS X 10.0, em 2001. Entre suas versões conhecidas estão 10.4 Tiger, 10.6 Snow Leopard, 10.7 Lion e 10.9 Mavericks. A partir do macOS 10.12 Sierra, lançado em 2016, a Apple adotou o nome macOS. Depois vieram macOS 10.15 Catalina, macOS 11 Big Sur, 12 Monterey, 13 Ventura, 14 Sonoma e 15 Sequoia. Em 2025, a Apple passou para a numeração baseada no ano e lançou o macOS 26 Tahoe. As versões podem trazer mudanças de interface, segurança e integração com outros dispositivos Apple, e a compatibilidade depende do modelo do Mac.

Linux e suas distribuições

Linux é o núcleo (kernel) de um sistema operacional. Criado por Linus Torvalds em 1991, ele administra recursos do computador e é desenvolvido como software de código aberto. O kernel recebe versões próprias, identificadas por números; a série 6.x, por exemplo, representa versões do núcleo, não uma edição única de todo o sistema operacional. Um sistema Linux completo geralmente é distribuído como uma distribuição, que combina o kernel com programas, ferramentas e uma interface. Ubuntu, Debian, Fedora e Linux Mint são exemplos. Cada projeto publica suas próprias versões: Ubuntu 22.04 e 24.04 são versões LTS, planejadas para oferecer suporte prolongado; Debian 12 e 13 identificam lançamentos do Debian. Por isso, ao falar em “versão do Linux”, é importante especificar se o assunto é o kernel ou uma distribuição.
